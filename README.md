# 📊 Retail Analytics BI Dashboard (Power BI Project)

## 🚀 Project Overview

This is an end-to-end Business Intelligence dashboard built using Power BI.

The project provides a complete retail performance analysis across:
- Sales Performance
- Customer Analytics
- Product Insights
- Returns & Risk Analysis
- Executive Overview

The goal of this dashboard is to transform raw transactional data into actionable business insights for decision-makers.

---

## 🧠 Business Objectives

- Monitor overall sales performance
- Identify top and underperforming customers
- Analyze product profitability
- Track return rates and financial loss
- Detect high-risk regions contributing to returns

---

## 📌 Dashboard Pages

### 1️⃣ Executive Overview
- Total Sales
- Total Profit
- Total Orders
- Key Growth Indicators

### 2️⃣ Sales Analysis
- Sales by Region
- Sales Trend by Year
- Category Performance

### 3️⃣ Customer Analytics
- New vs Repeat Customers
- Churn %
- Top 10 Customers by Revenue
- Segment Distribution

### 4️⃣ Product Insights
- Product Contribution (Tree Map)
- Product vs Profit Matrix
- Best Product KPI
- Worst Product KPI

### 5️⃣ Returns & Risk Analysis
- Return %
- Loss Due to Returns
- Return Rate by Region
- Returned vs Non-Returned Orders
